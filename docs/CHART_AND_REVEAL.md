# 未到達称号とカテゴリーグラフ v0.12.0

トップ画面は共通レベル・役職の下に、選択中の全カテゴリーの横棒グラフを表示します。5つの区切りはカテゴリーのレベル1〜5に対応し、濃い色は挑戦合格、薄い色は現在地、灰色は未解放です。現在のレベル番号を併記し、カテゴリーを押すとスキルツリーへ進みます。通常サイズの幅がある画面では2列、小さい画面・文字拡大時は1列になります。カテゴリーを多く選んだ場合も一つのグラフにまとめ、必要に応じて画面をスクロールできます。

未到達の共通役職と、未解放のカテゴリー称号は「？？？」で表示します。次の役職の案内、役職一覧、スキルのボタンと長押しヒント、未解放カード、前段階の説明、旧問題の復習ラベルも同じ表示です。到達・解放後は実際の名前が分かります。現在と過去に解放した名前、必要レベル番号は表示します。

全カテゴリーのEXP合算、8段階の共通役職、カテゴリーごとの5段階、通常8割→挑戦8割の条件は維持します。表示だけの変更で、保存キー・問題ID・学習記録・挑戦合格・EXPを移行したりリセットしたりする必要はありません。

共通役職・カテゴリー称号の全名称は開発用のdocs/TITLES.mdやソースに定義されています。アプリの画面では未到達の名前を伏せます。

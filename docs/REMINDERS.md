# 学習リマインダー v0.13.0

トップ右上のベルから設定する、端末内で完結する毎日1回のローカル通知。

- 初期状態はオフ、初期時刻は20:00。時刻を選び、通知するスイッチをオンにして「設定を保存」。通知許可は保存またはテスト通知の明示操作時だけ求める。
- 「テスト通知」は即時の別ID通知。毎日の設定をオンにせず、保存時刻も変更しない。
- 通知を押すとアプリを開く。バックグラウンド・終了中もOSの予約で通知。Androidの強制停止中や端末独自制限・集中モードなどでは配信されない場合がある。
- AndroidはinexactAllowWhileIdle。正確なアラームの特別権限を求めず、設定時刻を目安に配信するため、OSの都合で遅れる場合がある。秒単位・分単位の厳密な配信は保証しない。
- タイムゾーンは端末から取得。次回日時はローカルの暦日で計算。起動・復帰時に保存設定を再予約し、旅行後の時差変更も次回起動で反映。
- Androidの再起動・アプリ更新はプラグインのBootReceiverで予約を復元。iOSはOSの繰り返しローカル通知を使用。
- ID71001を予約更新で使い回し、時刻変更で予約を増やさない。オフでは71001とテスト用71002を解除。
- 設定はSharedPreferencesAsyncのinkuri.reminder.v1。学習データphrase_flow.progress.v1とは独立。拒否時は有効化せず、端末の通知設定へのボタンを表示。予約・保存の失敗時は前の予約へ戻す。
- 起動時の復元とユーザーの保存操作を直列化し、古い予約が新しい時刻を上書きしないようにする。
- 対象はAndroid/iOS。他プラットフォームでは操作を無効にして対応端末を説明する。

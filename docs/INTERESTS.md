# 興味カテゴリーと出題（v0.10.0）

## 分野の選択
ホームの「興味のある分野を選ぶ」または初回の「スキルツリーを見る」から、1つ以上の分野を選ぶ。複数選択でき、上限は17分野。選択後もホームからいつでも変更できる。取消では変更を保存しない。保存失敗時は選択状態を保ち、再試行できる。

分野は次の17種類：
- 美容/コスメ
- 健康/医療
- グルメ/料理
- ファッション
- エンタメ/芸能
- ライフスタイル
- 出産/育児
- 学び/資格
- 恋愛/結婚
- ペット
- ゲーム/アニメ
- ビジネス/経済
- 旅行/観光
- 自動車
- 家電/ガジェット
- スポーツ
- 金融/マネー

## 問題とツリー
v0.8.0で1,178問を追加し、全1,733問とした。14分野は合計100問（初級34・中級33・上級33）。既に100問を超えているライフスタイル103問、ビジネス/経済115問、旅行/観光115問はそのまま維持する。カテゴリーをまたいだ同一問題の二重計上はしない。

新規問題は各分野の場面・語彙を使い、同じ場面を難易度別に段階練習できる構成。初級は予定・必要性・依頼・可能性、中級は行動の順序・間接疑問・現在完了・比較、上級は仮定法・助動詞と完了形・過去の振り返りを扱う。すべて主解答・別表現と双方のニュアンス解説を持つ。全3,467例文を同じ声の同梱音声で再生する。

v0.7.1までの555問の全レコードと1,111音声は内容・ID・パス・ハッシュを維持する。保存キーとデータ形式も変えない。教材の追加後も記録・EXP・獲得バッジを引き継ぐ。v0.10.0の5段階解放は新しい挑戦ルールで判定する。RANKは拡充後の問題総数に対して再計算するため、旧5問コースの全問クリアが拡充後の全問クリアを意味するものではない。

旧300問の本文・ID・解説と旧601音声は維持する。旧問題にはJSONを書き換えず、IDや旧シーンに基づく対応カテゴリーを割り当てる。旅行の旧問題は旅行/観光、仕事はビジネス/経済、日常はライフスタイルを基本とし、体調・服・食事・エンタメに該当する固定IDは対応カテゴリーへ分類する。

ツリーは1カテゴリー・1レベルだけを表示する。上部のカテゴリー選択で興味分野を一覧・検索し、5つのボタンでカテゴリーごとの5段階の称号を切り替える。上部は学習内容をスクロールしても固定される。カテゴリーを変えると最初の未合格の解放済み段階（全合格なら5）を表示。挑戦後も同じカテゴリーを開く。最後に開いたカテゴリーはアプリ起動中のみ記憶し、選択から外れた場合は先頭へ戻る。通常学習は対象段階から最大10問を重複なしで出題。

各コースのランクは問題数に応じた3段階。5問のコースは2問・4問・5問でRANK 1・2・3となる。問題数が多いコースは5問・15問・全問が目安。通常問題の8割クリアで挑戦を開き、その回の挑戦で8割「できた」を達成すると次のレベルを開放する。通常は5問中4問。過去の評価のみで新ルールを迂回しない。

## 保存と復習
選んだ分野のIDを、既存の端末内の学習データに任意のinterestsとして追加する。保存キー・schemaVersionは維持。旧データは選択がない状態として読み、最初に利用者が分野を選ぶ。未選択ではツリーへ進まず、選択画面を案内する。

分野を外しても、挑戦の合格・EXP・レベル・過去の評価・時間・起動日・バッジは消さない。同じ分野を再度選ぶと、その問題IDの記録から進捗が復元される。学習記録のリセットは学習実績だけを消し、分野の選択は保持する。

「まだ難しい」で残した問題は、選択中でないカテゴリーも含め、トップ画面の「復習」からまとめて復習できる。SNS共有文には分野の選択や個別問題を含めず、期間別の問題数・時間だけを渡す。

## 開発用のデータ契約
カテゴリーIDはbeauty / health / food / fashion / entertainment / lifestyle / parenting / learning / relationships / pets / games / business / travel / cars / gadgets / sports / money。表示名を変えても保存先のIDを維持する。

Questionの任意のcategoryがない既存問題は、互換用のcategoryForQuestionで分類する。未知のカテゴリーIDや重複した選択IDはエラーとして扱い、破損データを黙って上書きしない。旧sceneは既存データとの互換性のため残すが、UIのカテゴリー選択ではcategoryを使う。

## 5段階への割り当て
教材の旧level（初級・中級・上級）は互換用に保持する。カテゴリー内を旧難易度順、同難易度内はID順に並べ、連続した5群へ均等分割する。100問は20問ずつ、103問は21/21/21/20/20、115問は23問ずつ。重複・欠落なく全1,733問を活用する。JSONの並び替えだけでは所属段階は変わらない。将来の問題追加時には均等分割により所属が変わり得るため教材更新時に再検証する。問題文・別表現・解説・ID・音声は変更しない。


## カテゴリー別の称号（v0.10.2）
「入門・基礎・実践・応用・発展」という共通の表示名を、カテゴリーごとの5段階の称号へ変更した。表示例は旅行「旅じたくの見習い → 街角の探検家 → 国境を渡る旅人 → 世界の案内人 → 七つの海の冒険家」。段階・問題割り当て・保存キーを保持し、更新前の挑戦合格と現在地をそのまま引き継ぐ。全85称号と表示仕様は[TITLES.md](TITLES.md)を参照。


## トップ画面と共通成長（v0.11.0）
カテゴリー別カードを縦に並べる表示を廃止し、1カテゴリーだけを表示するコンパクトな切替カードに変更。切替一覧で各カテゴリーの称号を確認・検索できる。共通レベル・役職をトップ最上部へ配置し、全カテゴリーのEXP合算で8段階の役職へ成長する。既存のXP・レベル・保存形式を維持する。過去のトップ一覧・折りたたみ表示の説明は旧版の記録。現在の仕様は[COMMON_GROWTH.md](COMMON_GROWTH.md)を参照。

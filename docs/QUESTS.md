# 復習ショートカットとクエスト v0.15.0

トレーニング画面上部に、冒険・修行モード共通の「復習（N問）」と「クエスト」を固定表示する。

## 復習

- 学習記録のページを経由せず、両モードの苦手問題から最大10問をすぐに練習できる。
- 対象0問では無効。修行モードでは文法ページから単元ごとに復習することもできる。
- 評価直前に苦手だった問題を再び自己評価すると、正誤を問わず当日の復習回数に加える。初めて「まだ難しい」とした評価は復習回数に含めない。

## クエスト

- はじめの一歩：当日1問の自己評価で10 EXP。
- ことばの鍛錬：当日10問の自己評価で30 EXP。復習・繰り返しも対象。
- ことばの大特訓：当日30問の自己評価で60 EXP。復習・繰り返しも対象。
- 苦手を味方に：当日1問の復習で20 EXP。まだ難しい評価も対象。苦手問題がない日は他のクエストだけでよい。
- 今週の冒険：月〜日の間に3日学習すると80 EXP。1問の自己評価で1日分。起動や時間だけでは進めない。
- 今週の大冒険：同じ条件で週に5日学習すると120 EXP。
- 無料版では、日替わり4件すべての達成で追加練習チケット1枚を受け取れる。週間の3日・5日の報酬にも、それぞれ1枚が付く。
- 達成した報酬はボタンで受け取る。同じ期間・同じクエストは一度のみ。受け取り可能な数をトップのバッジで知らせる。
- 週間の学習日を7つの足あととして表示し、現在の学習継続日数を案内。未到来の日は実績に含めない。休んでも既得EXP・役職を減らさない。
- 報酬受け取り時にトロフィー・獲得EXP・レベルアップを表示。到達していない役職名は表示しない。

## 保存

既存のschemaVersion 1を読み込み可能なまま、reviewDaysとquestClaimsを省略可能な項目として追加。空の新項目は書き出さない。通常の評価EXPは維持し、受け取ったクエスト報酬のみ加算。日々の問題数や時間、カテゴリーの挑戦合否には報酬を加算しない。

記録更新・報酬受け取りを既存の保存キューで直列化する。保存成功前は学習状態を置き換えず、失敗時は再試行できる。二重タップでも同じキーを二度加算しない。キーは日付|クエストID。週間は週の月曜日の日付を使う。

復習回数を過去の評価から推定せず、新機能の追加後の評価から記録する。日替わりは端末時刻の午前0時、週間は月曜日に更新。クエスト画面は日付変更・復帰時に更新し、前の期間の受け取り操作は拒否する。学習記録リセットではクエスト・報酬も消去する。

実機テスト例：
flutter test integration_test/android_quests_test.dart --no-uninstall -d <端末ID>

既存端末の通常記録を退避した上で実施する。テストは専用の保存キーを使い、通常の学習記録・モード・通知設定を照合する。終了後は通常APKへ戻す。

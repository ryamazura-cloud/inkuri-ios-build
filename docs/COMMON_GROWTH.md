# 共通レベル・役職とトップ画面 v0.12.2

トップでは、選択した全カテゴリーの成長を5区画の横棒グラフでコンパクトに表示する。各カテゴリーを押すと該当スキルツリーへ進む。未解放の称号は「？？？」で表示し、挑戦合格で次の称号を開示する。

最上部の「共通レベル・役職」は、選択中かどうかに関わらず全カテゴリーの累計EXPで育つ。繰り返し・復習もできた10 EXP、まだ難しい5 EXP。獲得済みEXPを維持し、必要EXPを従来の3倍へ調整する。更新前のレベル・役職・進捗率を引き継ぎ、その後のレベルアップを緩やかにする。学習履歴やカテゴリーの解放状態は維持する。カテゴリー別の5段階称号とは別系統。

## 共通役職

- Lv. 1：ことばの旅人
- Lv. 5：会話の見習い
- Lv. 10：フレーズの使い手
- Lv. 15：対話の冒険者
- Lv. 20：表現の騎士
- Lv. 30：ことばの魔導士
- Lv. 40：会話の賢者
- Lv. 50：世界をつなぐ語り部
- Lv. 60：ことばの大魔導士
- Lv. 70：対話の導き手
- Lv. 80：世界を結ぶ賢者
- Lv. 90：ことばの英雄
- Lv. 100：伝説のことばの創造主

役職は共通レベルから算出する。旧データは初回読込時に引き継ぎ用の値を計算し、以後の保存・読込で重複加算しない。Lv.100で最終役職に到達し、その後も同じ役職のままレベルとEXPが上昇する。各役職の到達レベルと名称、評価・クエストで得るEXPは変更しない。引き継ぎ用の値と方式番号を保存データに追加する。必要な累計EXPは75×(レベル−1)×(レベル＋2)÷2。未到達の役職は「？？？」で表示する。役職名を押すと昇格一覧を開き、トップでは次の役職と必要レベルを表示する。レベルバーは従来どおり次の1レベルまでのEXP。興味分野の変更では減らず、学習記録のリセットではEXP・役職も初期化する。

選択分野を変更する設定は「スキルツリーを見る」の横の調整アイコン。分野未選択時は「興味のある分野を選ぶ」を表示する。

カテゴリーの1件表示・切替方式から、選択した全カテゴリーを横棒グラフでまとめる方式へ変更。未到達の共通役職・カテゴリー称号を「？？？」で伏せ、到達時に開示する。[CHART_AND_REVEAL.md](CHART_AND_REVEAL.md)を参照。以前のトップ表示の説明は旧版の記録。

## 更新前のレベルを引き継ぐ調整

新規利用者は必要EXPが従来の3倍の曲線から開始する。既存の保存データは初回読込時、levelXpOffsetを獲得済みEXPの2倍として計算する。レベル判定のみ獲得EXP＋levelXpOffsetを使い、表示する累計EXP・評価やクエストで獲得するEXPは増やさない。これにより旧レベル・役職・レベルバーの進捗率が保たれ、残りEXPが従来の3倍になる。

levelBalanceVersion=2とlevelXpOffsetを同じ進捗JSONへ保存し、以後は保存値を読み込む。すべての記録更新で固定値を引き継ぎ、再読込で再加算しない。レベル調整データが不正なら記録の読み込みを失敗させる。新規利用・学習記録リセット時はoffset=0。schemaVersion=1、問題IDや既存の学習記録を維持する。

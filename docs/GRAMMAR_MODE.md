# 修行モード v0.14.0

中学英文法を復習したい人向けに、トップから「冒険モード」と切り替える文法練習を追加する。

## 教材

参考：https://english.005net.com/youten.php （中学校英語学習サイト「中学英語の要点のまとめ」、2026-11-03確認）
文法項目を参考に、問題・例文・解説はインクリ用に独自作成。参考サイトの問題や解説文の転載は行わない。「関係代名詞2」のリンクは「関係代名詞1」へ移動するため、両方を主格・目的格の別単元として整理する。

assets/grammar.jsonに34文法×10問＝340問を同梱。冒険モードの既存1,733問を変更せず、合計2,073問になる。

- 中学1年生文法（16単元・160問）　be動詞、一般動詞、現在進行形、過去形など
- 中学2年生文法（7単元・70問）　未来、動名詞、不定詞、助動詞、比較、接続詞、受け身
- 中学3年生文法（11単元・110問）　現在完了、現在完了進行形、関係代名詞、仮定法など

学年の区分は、東京書籍「NEW HORIZON」の年間指導計画を参考にした復習用の目安。複数の学年で扱う内容は、既存の単元をまとめて復習できる学年に置く。

## 画面と学習

- トップ上部の切り替えは共通EXPカードの上。通常幅は2つのボタン、小画面や文字拡大時は選択リストにする。
- 修行モードではカテゴリーの横棒・スキルツリー導線を文法一覧へ置き換える。「学年をえらぶ」で3学年を切り替え、選んだ学年の単元を表示する。初期表示は「中学1年生文法」。
- どの文法も最初から選択可能。文法名→ひとくちメモと基本の形→10問の瞬間英作文。10問を重複なくランダム順に出題する。
- 答え表示で例文・文法の解説・同梱音声を表示。短縮形や目的格の関係代名詞省略など、同じ文法の範囲で別表現を一部用意する。let usの許可とlet'sの勧誘のように意味が変わるものは同一解答として扱わない。
- 自己評価は従来の「できた」「まだ難しい」。文法ごとの苦手問題だけの復習も可能。トップ画面の「復習」からも両モードの苦手問題をまとめて復習できる。
- 文法一覧の進捗は「学習済み / 10問」。できた問題数は表示しない。

## 保存と互換性

- 文法IDはgrammar-<単元ID>-01〜10で固定。Questionに省略可能なgrammarUnitを追加し、既存の問題をそのまま読み込む。
- 評価・学習時間・日別実績・復習対象・EXP・バッジは既存のLearningDataと共通。修行でもできた10EXP、まだ難しい5EXP。レベル・役職の算出方法は維持。
- カテゴリーの問題割り当て・5段階・8割と挑戦合格の条件には文法問題を含めない。既存の挑戦合格を引き継ぐ。
- モード選択は別キーinkuri.training_mode.v1へ保存し、アプリ再起動後も保持する。読み込み不能時は冒険モードで継続し、保存に失敗した時は元のモードを維持する。
- 音声は既存と同じKokoro af_heart / fp32 / speed 1.0。既存の音声はファイルのハッシュを維持し、新しい英文分だけ追加。
- assets/grammar.jsonと音声はオフライン利用でき、更新で追加する。

## 開発時の確認

flutter test test/grammar_test.dart
flutter test integration_test/android_grammar_test.dart --no-uninstall -d <端末ID>

実機テストでは専用の進捗・モード保存キーを使い、通常の学習記録・モード選択・通知設定が変わらないことを照合する。試験用アプリで実機テスト後は通常APKを上書きして戻す。

追加音声369本、音声は全3,836本。既存3,467本は同一のまま保持。トップの切り替えはスクロール中も固定表示し、切り替え後は一覧の先頭へ戻す。



実機の既存アプリを使う場合は、実行前に学習記録を退避し、integration_testに必ず --no-uninstall を指定する。現在のFlutterでは既定で試験後にアプリを削除するため、無指定で実行しない。試験後は通常APKへ上書き更新して戻す。

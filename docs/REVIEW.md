# 復習が完了するまでの回数

「まだ難しい」を選んだ問題は復習対象になる。復習対象になってから「できた」を選んだ回数を数え、設定回数に達した時に一覧から外れる。初期値は5回。冒険・修行・復習、いずれの学習で同じ問題を評価しても共通で加算される。途中で「まだ難しい」を選んでも回数は戻らない。

iアイコンで開く「このアプリについて」の「復習設定」で1以上の整数を指定できる。設定を下げた時点で達成済みの問題は復習完了となる。設定を上げても、すでに完了した問題は戻さない。完了した問題を改めて「まだ難しい」とした場合は0回から再度復習対象になる。

設定と問題別の復習成功回数は同じローカル学習記録に保存。更新前に復習中だった問題は0回から開始し、既存の復習完了・評価回数・獲得EXP・カテゴリー・クエスト報酬は引き継ぐ。復習として評価した日は、結果に関係なく従来どおり復習クエストに計上される。学習記録のリセットでは問題の進捗を消し、復習設定の回数は維持する。

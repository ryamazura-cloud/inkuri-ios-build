# 学習記録・共有・バッジ仕様（v0.7.1）

## 名前とアイコン
表示名は「インクリ」。ヘッダーに吹き出しと成長を示すマーク、日本語のアプリ名を表示する。Android / iOS / Webの起動アイコンも同じ図柄。既存端末の記録を引き継ぐため、アプリIDと保存キーは変更しない。

## 学習数
「できた」「まだ難しい」の保存が成功したときに1問として計上する。同じ問題の繰り返しも加算。答えを表示しただけ、途中終了、保存失敗時には問題数を加算しない。

従来の問題ごとのattempts / successes / needsReview / lastStudiedは保持する。以前の記録は最終学習日しか分からないため、過去の全試行を特定の日へ割り振らない。日別・月別の集計は更新後の評価分から記録し、従来の累計は別途そのまま表示する。

## 学習時間
問題画面を前面で開いている時間をミリ秒単位で蓄積し、秒・分・時間に整形して表示する。考える時間、解答と解説を読む時間、音声を聞く時間を含む。未評価で終了した場合も、問題画面を見ていた時間は保存する。

背景・画面ロック・終了確認ダイアログ・保存待ち・学習完了画面は計測しない。保存に失敗した場合は未保存分を保持し、再試行で重複計上しない。15秒ごと、背景移動、自己評価、終了時に保存する。OSが保存前に強制終了した場合、最後の未保存分が失われる可能性がある。

端末のローカル日付で集計し、深夜0時をまたぐ区間は日別に分割する。時計が戻った区間を負の時間として加算しない。端末時計を大きく変更した場合の実時間の復元はしない。端末設定に基づく時計であり、学習中の操作がなくても前面に問題が表示されていれば計測する。

## 集計とグラフ
今日・今週・今月に、それぞれ学習問題数と学習時間を表示する。週は月曜から日曜、月は暦月。日別グラフは直近14日、月別グラフは直近12か月を表示し、前後の矢印で過去の期間も確認できる。未来の期間には進まない。

学習記録の一番上に、問題数を緑の棒（左軸・問）、時間をオレンジの折れ線（右軸・分）で重ねた1つの複合グラフを表示する。左右は独立した目盛りである旨を明記する。日付の列をタップするとその日の問題数・時間が分かる。0件の日も省かない。小さな画面ではグラフ内を横スクロールできる。各日付の列に日付・問題数・時間の読み上げ用ラベルを付ける。

## SNS共有
共有ボタンは「学習記録をまとめて共有」の1つ。押すと、今日・今週・今月すべての期間・問題数・学習時間を含む1つの共有文とハッシュタグのプレビューを表示する。「コピー」または「共有先を選ぶ」を明示的に選べる。個別問題、解答、苦手問題の内容を共有文に含めない。

共有先はOS標準の共有画面で選ぶ。投稿の確定は共有先アプリで行う。アプリ側は自動投稿やログイン情報の取得を行わない。共有先アプリによって受け取れる形式は異なる。共有画面が利用できない場合はコピーから利用できる。

共有実装：[share_plusの公式ドキュメント](https://pub.dev/packages/share_plus)。iPad向けに共有元のボタン位置も渡す。iOS実機はWindows環境では未検証。

## バッジ
バッジは計50個。連続起動12個、異なる問題のクリア12個、累計学習問題数10個、累計学習日数8個、挑戦合格数8個。学習記録では1ページに最大8個を表示し、矢印で全7ページを切り替える。

達成日は保存済みの起動日・日別学習記録・挑戦合格日から判定する。クリアバッジは問題ごとに初めて「できた」を保存した日で判定する。初回クリア日を保存していない過去のクリアも獲得判定に含め、日付を特定できない獲得済みバッジは「達成日不明」と表示する。

ログイン機能は設けず、起動日を端末に記録する。毎日の起動または学習で日付を追加し、同日は1日として扱う。継続バッジの判定は最長連続日数を使い、連続が途切れても獲得済みバッジは残る。現在の連続日数も別に表示する。

クリアは一度以上「できた」にした問題の数。同じ問題の繰り返しでは増えず、後から「まだ難しい」にしても獲得済みバッジは取り消さない。従来のsuccessesから判定できるため、過去にクリアした問題も含める。未獲得バッジには条件と現在の進捗を表示する。

## 保存とリセット
既存のschemaVersion 1、保存キー phrase_flow.progress.v1を維持し、任意のdays / visitsを追加する。古い形式に両項目がなければ空として読み込む。壊れた日付・負の時間などは読み込みエラーとし、元の記録を上書きしない。評価・時間・起動日の書き込みは直列化する。

選択した興味分野は学習記録のリセット後も保持する。リセットは学習回数・苦手問題・日別集計・学習時間・起動日・バッジをすべて消すことを確認画面に明記する。取消では何も削除しない。

## できた問題数の表示
学習記録とトレーニングの累計カードから「できた問題数」とその割合バーを削除する。トレーニング完了画面の「できた N問」も表示しない。評価ボタン、苦手件数、学習済み件数・学習回数、EXP・スキル・バッジの判定に使う記録は維持する。

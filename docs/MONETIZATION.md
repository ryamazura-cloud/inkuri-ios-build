# インクリの収益化の試用版

AndroidまたはiOSのデバッグビルドを `--dart-define=INKURI_MONETIZATION_TEST=true` 付きで起動すると試せます。広告はGoogle提供のテスト枠です。通常ビルドでは試用機能はオフです。

- 冒険と修行の通常練習・復習は、合わせて1日3セット。端末の現地時刻で午前0時に無料枠が戻ります。セットを開始した時点で1回を消費します。挑戦問題と初回操作ガイドは対象外です。
- ベルの横に、円形ゲージで無料枠の残り（例 3/3）と追加チケットの枚数を表示します。タップすると有料プランの案内が開きます。無制限プランでは「∞」を表示します。
- 無料枠を先に使い、追加練習チケット1枚で最大10問の1セットを追加できます。チケットは最大3枚まで日付をまたいで持ち越せます。共通レベルアップ、今日のクエスト全達成、週間クエスト（3日・5日）の報酬で獲得します。チケットが満杯のときは、空きを作ってから期限内にクエスト報酬を受け取れます。
- 無料枠とチケットが両方なくなった後に次のセットを開始しようとすると、任意のリワード広告と「有料プランを見る」を同じ画面に表示します。視聴条件を満たした場合に、1日1回までチケットを1枚受け取れます。
- 無料版はTOP、学習記録、10問終了後の成果画面にバナーを各1枠表示します。枠を確保できない画面幅や広告取得に失敗した場合は表示しません。有料版は通常練習・復習の上限がなく、広告も表示しません。

## 購入を試す場合

ストアのテスト環境に買い切り商品 `inkuri_unlimited` を用意し、テスト購入者のアカウントと `--dart-define=INKURI_STORE_SANDBOX=true` を使います。商品が取得できたときにストアの価格が表示されます。購入または復元の通知で無制限になり、保留やキャンセルでは解放されません。

公開前に本番の広告IDとストア商品を設定し、購入のサーバー検証と取り消し時の権利確認、広告同意とプライバシー設定を用意します。試用版はストアの通知で動作を確認するためのもので、本番の購入検証は含みません。

# カテゴリー別称号 v0.10.2

各カテゴリーのレベル1〜5に対応するオリジナルの称号。トップ・スキルツリー・前段階の解放説明・トレーニング・挑戦・苦手問題の表示を統一する。段階番号は併記し、現在地を把握できるようにする。ゲームの固有職業名や台詞は使用せず、このアプリのカテゴリーに合わせて命名した。

- 美容/コスメ：鏡の見習い → 彩りの使い手 → 美肌の案内人 → 輝きの仕立て屋 → 美の錬金術師
- 健康/医療：からだの探究者 → 元気の応援団 → 健やかの案内人 → いのちの守り手 → 健康の賢者
- グルメ/料理：食卓の見習い → 味の探検家 → 香りの料理人 → 美食の伝道師 → 食卓の魔術師
- ファッション：おしゃれの卵 → 装いの冒険者 → 着こなしの職人 → 流行の仕掛け人 → 装いの創造主
- エンタメ/芸能：推し活の新人 → 話題の追い人 → エンタメ通 → 熱狂の仕掛け人 → 舞台裏の賢者
- ライフスタイル：暮らしの見習い → 日々の工夫家 → 心地よさの職人 → 暮らしの演出家 → 日常の錬金術師
- 出産/育児：見守りの芽 → 笑顔の応援団 → 子育ての伴走者 → 安心の守り手 → 家族の太陽
- 学び/資格：学びの旅人 → 知識の収集家 → ひらめきの使い手 → 知恵の探究者 → 学びの大賢者
- 恋愛/結婚：ときめきの旅人 → 心の聞き上手 → 想いの橋渡し → 絆の紡ぎ手 → 愛の語り部
- ペット：もふもふ見習い → しっぽの友だち → お世話の達人 → 心をつなぐ相棒 → どうぶつの賢者
- ゲーム/アニメ：物語の旅人 → クエストの挑戦者 → コンボの使い手 → 世界を渡る勇者 → 伝説の冒険王
- ビジネス/経済：仕事の見習い → 段取りの使い手 → 交渉の戦略家 → チームの導き手 → 未来の開拓者
- 旅行/観光：旅じたくの見習い → 街角の探検家 → 国境を渡る旅人 → 世界の案内人 → 七つの海の冒険家
- 自動車：ドライブ見習い → 街道の旅人 → ハンドルの職人 → 大地の探検家 → 走りのマイスター
- 家電/ガジェット：スイッチの見習い → 便利の発見者 → ガジェット使い → 電脳の探検家 → 未来の発明家
- スポーツ：ウォームアップ隊員 → 挑戦の走り出し → 技の磨き手 → 勝利の戦略家 → 限界を超える覇者
- 金融/マネー：コツコツ見習い → 家計の守り手 → お金の計画家 → 資産の航海士 → 未来を築く賢者

称号は表示名のみ。stage-1〜stage-5のキー、問題割り当て、挑戦合格、評価・EXP、全レベル達成の判定を変更しない。新たに挑戦をやり直す必要はない。文字を大きくした場合、スキルツリー上部はLv.1〜5のコンパクトなボタンを使用し、選択中のカードに完全な称号を表示する。長押しのヒントでも各称号を確認できる。

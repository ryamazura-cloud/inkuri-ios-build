# 挑戦問題と難易度の解放 v0.10.0

## ルール
各分野はレベル1から始め、レベル2・3・4・5へ順に進む。各段階はカテゴリーごとのオリジナル称号で表示する（TITLES.md参照）。各レベルの異なる通常問題を一度以上「できた」にした数が8割に達すると挑戦を解放する。必要数はceil(総問題数×0.8)。20問なら16問、21問なら17問、23問なら19問。同じ問題の繰り返しや「まだ難しい」だけでは増えない。

挑戦は同じレベルの全問題からランダムに5問を重複なしで出題する。通常問題の再評価も同じ問題IDへ記録する。5問のない小規模カタログでは存在する問題数に合わせ、合格数も8割の切り上げとする。

その1回の挑戦で4/5問以上「できた」なら合格。別の挑戦の結果を合算しない。途中で終了した場合、回答済みの学習記録と時間は保存し、挑戦の合格は付けない。再開は最初からの別の挑戦となる。

各レベルの挑戦合格で次の段階を解放し、レベル5合格がそのカテゴリーの最終達成となる。既存の問題評価とEXPは維持する。旧3段階の挑戦合格は別キーで保持し、新5段階の合格に自動変換しない。苦手に登録済みの問題の復習は引き続きできる。

解答表示後の「できた」「まだ難しい」で判定する自己評価方式。客観的な発音・正誤の自動採点は行わない。合格済みなら、後から再挑戦に失敗しても合格と次段階の解放は失わない。

## 保存
保存キー phrase_flow.progress.v1 と schemaVersion 1を維持し、任意のchallengePassesを追加する。未対応の旧記録では空として読み込む。

キーは categoryId|stage-1 ～ stage-5。旧categoryId|初級・中級・上級も読み込み・保持する。値は初回合格時の score（4等）、total（5等）、passedAt（ISO日時）。既知の分野・難易度、有効な点数・出題数・日時を検証する。不正な記録では読み込みエラーとし、元の記録を上書きしない。

挑戦の最終問題の評価と合格を、同じLearningDataの1回の保存で確定する。保存失敗では結果画面に進まず、同じ最終問題の評価を再試行する。これにより合格だけ先に付く、最後の評価が二重に付くことを防ぐ。

日付追加・学習時間・自己評価・分野の変更のいずれでも合格記録を保持する。学習記録リセットは合格記録も削除し、興味分野の選択だけを残す。合格自体に追加EXPは付けず、各自己評価の10/5 EXPを従来通り付与する。
